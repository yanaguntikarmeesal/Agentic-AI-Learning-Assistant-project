# 🤖 Agentic AI Learning Assistant

## 📌 Project Summary

The **Agentic AI Learning Assistant** is an interactive web application built using **Streamlit, Groq, and LangChain**. It demonstrates how an AI agent can understand user requests, use a custom tool, and maintain conversation memory.

The application uses a Groq-powered language model and a single custom tool called `text_assistant` to summarize text and answer questions based on provided context. It also includes an interactive chatbot and a learning section to help beginners understand the fundamentals of Agentic AI.

## ✨ Key Features

* 💬 **AI Chatbot:** Interact with a Groq-powered AI assistant.
* 📝 **Text Summarization:** Generate concise summaries of long text.
* ❓ **Question Answering:** Answer questions using the supplied context.
* 🧰 **Custom Tool Integration:** Uses one LangChain tool named `text_assistant`.
* 🧠 **Conversation Memory:** Maintains conversation state using LangGraph.
* 📘 **Learning Section:** Understand agents, tools, and memory.
* 🎨 **Interactive UI:** Clean and user-friendly Streamlit interface.

## 🛠️ Technologies Used

* Python
* Streamlit
* LangChain
* LangChain-Groq
* LangGraph
* Groq LLM

## 🎯 Project Objective

The main objective of this project is to understand the practical implementation of Agentic AI by building an AI assistant that can process user requests, use a custom tool, and maintain conversation context through a simple web interface.

## 🚀 Applications

* Learning Agentic AI concepts
* Summarizing educational content
* Context-based question answering
* Exploring LLM tool integration
* Practicing AI application development
